# turn based RPG framework

# a modular turn based combat system developed for unity in C#

## Overview

This project focuses on building an extensible combat architecture designed around reusable systems and data-driven content creation.

## Features

- Action value based turn system
- Modular skill and effect framework
- ScriptableObject-driven content creation
- Combat context system for damage, healing, shielding, and resource changes
- Status effects with durations and triggers
- Passive ability hooks
- Enemy AI with intent-based decision making
- Team resource management (SP/TP)
- Battle UI with skill selection and targeting

## Technologies

- Unity
- C#
- Git

## Design Goals

The goal of this project is to create a combat framework where new mechanics can be added primarily through composing existing systems rather than writing new behavior from scratch.
